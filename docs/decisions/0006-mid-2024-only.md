# 0006. Reference date mid-2024 only; provisional mid-2025 deferred
Status: accepted
Date: 2026-10-01

## Context
Mid-2024 LSOA estimates (released Nov 2025) are the latest official small-area estimates. The brief offered an optional
provisional mid-2025 variant scaled to the mid-2025 LA MYE. The user chose **mid-2024 only** (Phase 1 review).

## Decision
`reference_year: 2024`, `mid2025.enabled: false`. Stage E is registered in the CLI but not built. Phase 2 will still
check whether ONS has published mid-2025 **LSOA** estimates and report back. If it has, a new ADR will decide whether to
move the reference year.

## Update 2026-10-01 (Phase 2)
ONS has **not** published mid-2025 LSOA estimates. The release calendar lists "Population estimates by output areas,
electoral, health and other geographies, England and Wales: mid-2025" as provisional for **December 2026 to January
2027**. The mid-2025 LA estimates were published on 29 July 2026 (S6, disabled). Revisit this decision when the LSOA
release lands.

## Consequences
Outputs are for 30 June 2024. Users needing 2025 must wait, or ask for Stage E to be built.
